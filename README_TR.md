# 🛠️ Web Sitesi Bakım & Geliştirme Sayfası

Bu depo, web sitenizin geliştirme aşamasında veya bakımda olduğunu modern ve şık bir arayüzle ziyaretçilerinize duyurmanız için hazırlanmıştır.

## 📂 Dosya Yapısı

* `index.html`: Ana arayüz ve bakım sayfası HTML yapısı.
* `styles.css`: Modern cam efekti (glassmorphism), animasyonlar ve duyarlı (responsive) tasarım kuralları.
* `script.js`: İlerleme çubuğu animasyonu ve e-posta kayıt formu etkileşimleri.
* `README_TR.md`: Türkçe kurulum ve kullanım rehberi.

## 🚀 GitHub Pages ile Nasıl Yayınlanır?

1. Bu dosyaları (klasör içindekileri doğrudan ana dizine gelecek şekilde veya bir klasör olarak) GitHub deponuza (`repository`) yükleyin.
2. Deponuzun üst menüsünden **Settings** (Ayarlar) sekmesine gidin.
3. Sol menüden **Pages** seçeneğine tıklayın.
4. **Build and deployment** bölümündeki **Branch** kısmını `main` (veya `master`) ve `/ (root)` olarak ayarlayıp **Save** butonuna basın.
5. Birkaç dakika içinde siteniz `https://kullaniciadi.github.io/depoadi` adresinde yayına girecektir.

## 💡 Özelleştirme İpuçları

* **İlerleme Oranı:** `script.js` dosyasındaki `targetPercentage` değerini değiştirerek tamamlanma yüzdesini güncelleyebilirsiniz.
* **E-posta Kayıtları:** E-posta formunu aktif hale getirmek için [Formspree](https://formspree.io/) veya benzeri statik form servislerini entegre edebilirsiniz.
