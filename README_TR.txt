HAVATEAM.TR — ÜCRETSİZ SİTE BAŞLANGIÇ DOSYALARI

Bu paket, koyu temalı statik site başlangıç şablonudur. Henüz gerçek eklenti bilgileri ve görseller eklenmemiştir.

İLK AŞAMADA YAPILACAKLAR
1. Cloudflare hesabı açın: https://dash.cloudflare.com/sign-up
2. GitHub hesabı açın: https://github.com/signup
3. Bu klasörü bir GitHub deposuna yükleyin.
4. Cloudflare Pages > Create a project > Connect to Git seçin.
5. Depoyu bağlayın. Framework preset: None. Build command boş. Build output directory: /
6. İlk yayınlamadan sonra verilen *.pages.dev adresinde siteyi test edin.
7. Domain bağlama aşamasında havateam.tr alan adının DNS yönetimini Cloudflare'a göre yapılandırın. Mevcut e-posta/DNS kayıtlarını korumadan nameserver değiştirmeyin.

LİVERY EKLEME
- liveries/sample-livery.html dosyasını kopyalayarak her eklenti için yeni detay sayfası oluşturun.
- Sayfa başlığını, uçak/uyumluluk/sürüm/açıklama bilgilerini değiştirin.
- İndirme butonunun URL'sini ilgili Flightsim.to sayfasıyla değiştirin.
- index.html içindeki örnek kartı çoğaltıp yeni detay sayfasına bağlayın.
- Görselleri assets klasörüne koyup karttaki placeholder alanını görsel olarak düzenleyin.

ÖNEMLİ
Bu bir ilk taslaktır; gerçek livery listesi, görseller, açıklamalar ve bağlantılar henüz eklenmemiştir.
