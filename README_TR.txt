HAVATEAM LOGOLU BAKIM SAYFASI
==============================

GitHub ana dizinine yüklenecek dosyalar:
- index.html
- styles.css
- script.js

Logo seçimi:
- Üst bölümde yatay HavaTeam yazılı amblem: https://i.hizliresim.com/vazspbbp.png
- Radar alanında mavi kalkanlı HTR amblemi: https://i.hizliresim.com/xuw0on5v.png

Not: Logolar şu anda HızlıResim üzerindeki bağlantılardan çağrılır. Bu nedenle görsellerin orada erişilebilir kalması gerekir. Daha kalıcı çözüm, PNG dosyalarını GitHub deposunda assets klasörüne yükleyip HTML'deki görsel adreslerini yerel dosya yollarına çevirmektir.

Kurulum:
1. ZIP'i bilgisayarınızda ayıklayın.
2. Üç dosyayı havateam-website deposunun ana dizinine yükleyin.
3. Mevcut index.html, styles.css ve script.js dosyalarının üzerine yazın.
4. liveries klasörünü silmeyin.
5. Commit changes ile kaydedin.
